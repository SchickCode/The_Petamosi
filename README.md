# The_Petamosi
This is the Repository for my Hack Club Project

The Petamosi is designed to be a radio that also has drone abilities.
- There are two main parts to the device
  - The radio
  - The remote

You can turn on the radio by either the radio itself or the remote. The only way to tune the radio is by directly interacting with the radio part. The drone section can only be activated by the remote. The remote uses wireless software to control the other section instead of infared so you do not have to always point the remote at a spot for it to work.

# Purpose

The reason to why I wanted to make this was to understand how to make both radios and drones. This project is able to combine both of my wants. I also saw in my research that interferance can happen between radios and motors because of the magnetic static they make, so I wanted to show how they can live side by side and still function normally.
